Substitution as a simplifying weapon

A messy expression is often a clean one wearing a disguise. Give the disguise a single letter, and the mess disappears.

You already own this move

You have seen this: if u + 1/u = 5, what is u² + 1/u²? 

(u + 1/u)² = u² + 2 + 1/u² = 25
                   u² + 1/u² = 25 − 2 = 23

That is substitution in action: you never solved for u. You treated the whole chunk u + 1/u as one thing, squared it, and read off what you wanted. The letter u is not a variable to solve for — it is a name for a shape.

The move, stated plainly

When you see the same messy chunk appearing more than once, give it a letter. The chunk becomes a single variable, and the expression becomes something you already know how to handle.

The pattern 1. Spot a chunk that repeats.
2. Name it (u, v, whatever).
3. Rewrite in the new letter.
4. Solve the simpler version.
5. Translate back if the question asks about the original.

Spotting a shape inside plain numbers

Here is the step the assessment was testing: 

What is  √(2⁴ + 4·2² + 4) ?

You could grind this out: 2⁴ = 16, 4·2² = 16, so 16 + 16 + 4 = 36, √36 = 6. Correct. But there is a shape hiding in it.

Let u = 2² = 4. Then: 

2⁴ = (2²)² = u²
4·2² = 4u
4  = 4

So the expression becomes:
  u² + 4u + 4

Do you recognise it? It is a perfect square: 

u² + 4u + 4 = (u + 2)²
            = (4 + 2)²
            = 6²
            = 36
  √36 = 6
What the shape is The expression u² + 4u + 4 is (u + 2)² — the expansion of a perfect square binomial. Once you see it, the square root is trivial. The entire move is spotting the quadratic shape, not doing arithmetic.

Another one

What is  √(5⁴ + 6·5² + 9) ?

Let u = 5² = 25. Then:

u² + 6u + 9

Recognise it:

u² + 6u + 9 = (u + 3)²
            = (25 + 3)²
            = 28²
            = 784
  √784 = 28

Same move, different shape. u² + 6u + 9 is (u + 3)². The 6 comes from 2 × 3, and the 9 is 3² — it is the two-terms-times pattern (a + b)² = a² + 2ab + b² in reverse.

How to spot them

Not every u² + bu + c is a perfect square. It is one only when the middle term is twice the square roots of the outer terms: 

u² + bu + c is (u + k)² when:
  c = k²      (the last term is a perfect square)
  b = 2k      (the middle term is exactly twice that root)
The check Look at the first and last terms. Take their square roots. Double one of them — if it equals the middle term, the whole thing is a perfect square.

Where else it lives

Substitution is not only for square roots. Any time a chunk repeats, naming it can turn a wall of symbols into something familiar:

  • Fractions with repeated chunks. If a mess contains (x − 1) everywhere, let v = (x − 1) and rewrite.
  • The x + 1/x family. Already yours — substitution is exactly what makes it work.
  • Equations that look quartic. An equation in x⁴ and x² but with no x³ or x term is secretly quadratic if you let u = x².

The skill is not the algebra — that you can do. It is noticing the shape. A blurred pattern is obvious once you give it a name; it is invisible until you do.

Practice

  1. Let u = 4². What is √(u² + 8u + 16)?
    Answer

    u² + 8u + 16 = (u + 4)² = (16 + 4)² = 20² = 400. √400 = 20.

  2. √(4⁴ + 8·4² + 16)
    Answer

    Let u = 4² = 16. Then u² + 8u + 16 = (u + 4)² = 20² = 400. √400 = 20. Same as above — the point is noticing without the letter being given.

  3. √(6⁴ + 10·6² + 25)
    Answer

    Let u = 6² = 36. Then u² + 10u + 25 = (u + 5)² = 41² = 1681. √1681 = 41. Check: c = 25 = 5², b = 10 = 2×5. Perfect square — the test works.

  4. Let v = x + 2. Simplify: (x + 2)² − 5(x + 2) + 6
    Answer

    v² − 5v + 6 = (v − 2)(v − 3) = (x + 2 − 2)(x + 2 − 3) = (x)(x − 1) = x² − x.

  5. u² + 12u + 36 — is this a perfect square? If so, write it as a square.
    Answer

    36 = 6² and 12 = 2 × 6, so yes: (u + 6)².
