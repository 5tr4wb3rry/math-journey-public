Lesson · The x + 1/x family, iterated

Climbing a ladder you built yourself

There is a family of problems that hand you x + 1/x and ask for a much bigger power. You are never told what x is, and you never need it. The interesting part is what happens when you have to use the same move twice.

Start here

If x + 1/x = 4, what is x⁴ + 1/x⁴?

You could try to find x. Doing so means solving x² − 4x + 1 = 0, which gives 2 ± √3 — irrational, ugly, and then you would have to raise it to the fourth power. That road is open and it is terrible.

The other road never finds x at all. It builds a ladder: from the first power to the second, then from the second to the fourth. Each rung is the same move.

The move

Square both sides and watch what appears in the middle.

(x + 1/x)²  =  x² + 2·x·(1/x) + 1/x²
            =  x² + 2 + 1/x²

The middle term is the whole point of this family. x times 1/x is 1, so 2·x·(1/x) is just 2 — a plain number, no x in it. Rearranging: 

x² + 1/x²  =  (x + 1/x)² − 2

With x + 1/x = 4:

x² + 1/x² = 4² − 2 = 16 − 2 = 14
Why the middle term vanishes so neatly Because x and 1/x are reciprocals, their product is exactly 1. That is the only reason this family works at all — it would not happen for x + y.

The second rung — where it gets interesting

Now you want x⁴ + 1/x⁴, and you already have x² + 1/x² = 14. Here is the key idea: x⁴ + 1/x⁴ stands in the same relationship to x² + 1/x² as x² + 1/x² does to x + 1/x. Let u = x². Then 1/u = 1/x², and you are asking for u² + 1/u² given u + 1/u. Same problem. Same move. 

(x² + 1/x²)²  =  x⁴ + 2·x²·(1/x²) + 1/x⁴
              =  x⁴ + 2 + 1/x⁴

so   x⁴ + 1/x⁴  =  (x² + 1/x²)² − 2

Apply it to the 14 you just built:

x⁴ + 1/x⁴ = 14² − 2 = 196 − 2 = 194
Easy to miss Squaring the original 4 again instead of the result 14. The second rung starts from where the first rung left you, not from the ground. Each squaring doubles the exponent: 1 → 2 → 4. To reach the 4th power you square twice, and the second squaring acts on 14.

Written as one chain, so the shape is visible:

x + 1/x   = 4
x² + 1/x² = 4²  − 2 = 14
x⁴ + 1/x⁴ = 14² − 2 = 194

The cube is a different rung

Odd powers do not come from squaring, so the ladder needs a different step. Cube instead: 

(x + 1/x)³  =  x³ + 3x²·(1/x) + 3x·(1/x²) + 1/x³
            =  x³ + 3x + 3/x + 1/x³
            =  x³ + 1/x³ + 3(x + 1/x)

so   x³ + 1/x³  =  (x + 1/x)³ − 3(x + 1/x)

With x + 1/x = 4:

x³ + 1/x³ = 4³ − 3·4 = 64 − 12 = 52

Note the leftover here is not a plain number — it is 3(x + 1/x), which you happen to know. Different rung, different leftover; same principle of subtracting whatever the expansion added.

The ladder, in one place

Let s = x + 1/x.

x² + 1/x² = s² − 2
x³ + 1/x³ = s³ − 3s
x⁴ + 1/x⁴ = (x² + 1/x²)² − 2   ← built from the rung below, not from s

Memorising the third line as a formula in s is possible but pointless. Building it from the rung below is the same work and never goes wrong.

  5. Harder: if x + 1/x = 3, what is x⁶ + 1/x⁶?
    Answer322. Two routes, both fine. Square the cube: x³ + 1/x³ = 18, then 18² − 2 = 322. Or cube the square: x² + 1/x² = 7, then 7³ − 3·7 = 343 − 21 = 322. They must agree, and checking that they do is a free way to catch a slip.

What the check will ask

A two-step climb to a fourth or sixth power from a value of x + 1/x you have not seen here, and at least one where you must decide which rung to build first. Different numbers throughout.
