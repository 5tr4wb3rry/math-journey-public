Lesson · The x + 1/x family, iterated

A machine you can feed its own output

There is a family of problems that hand you x + 1/x and ask for a much larger power. They all fall to one move. The thing worth owning is not the move itself, though — it is that the move's output is the same kind of thing as its input, so you can put it straight back in and go again.

Start here

If x + 1/x = 3, what is x⁴ + 1/x⁴?

You are not told what x is. You could go and find it — that means solving x² − 3x + 1 = 0, which gives (3 ± √5)/2 — and then raising that to the fourth power by hand. That road is open, and it is genuinely awful.

So here is the question this lesson is really about: what is the smallest thing you could build that gets you from the first power to the fourth?

The machine

Square any expression of the form xⁿ + 1/xⁿ and watch what comes out: 

(xⁿ + 1/xⁿ)² = x²ⁿ + 2·xⁿ·(1/xⁿ) + 1/x²ⁿ
              = x²ⁿ + 2 + 1/x²ⁿ

The middle term collapses. xⁿ times 1/xⁿ is 1 no matter what x is and no matter what n is, so the middle term is exactly 2, always. Move it across: 

x²ⁿ + 1/x²ⁿ = (xⁿ + 1/xⁿ)² − 2

Read that as a machine. You feed it the value at some power, and it hands back the value at double that power. Square, subtract two.

Now look hard at what went in and what came out. In went a number that was the value of "some power plus its reciprocal". Out came a number that is also the value of "some power plus its reciprocal" — a different power, same shape. The machine's output is a legal input.

That is the whole lesson. Everything below is consequences.

Feeding it its own output

Start with x + 1/x = 3. Press the button once:

x² + 1/x² = 3² − 2 = 9 − 2 = 7

Seven is now a value of the same shape, so it is a legal input. Press again — and note carefully that what goes in is 7, the number that came out, not the 3 you started with: 

x⁴ + 1/x⁴ = 7² − 2 = 49 − 2 = 47

Done. x⁴ + 1/x⁴ = 47, and x was never found, never needed, never mentioned after the first line.

The machine has no memory. It cannot tell where its input came from, and it does not change on the second press. This is why "do it again" really does mean exactly the same thing the second time — there is no harder version of the move waiting further up.

A third press, just to see that nothing new happens: 

x⁸ + 1/x⁸ = 47² − 2 = 2209 − 2 = 2207

The numbers get big quickly. The method does not get harder at all — which means that from here on, the only thing that can go wrong is arithmetic. That is worth knowing, and the next section is the defence against it.

The free self-check

Every number this machine produces is two less than a perfect square — by construction, since the last thing it did was square something and subtract 2.

So any answer can be tested without redoing the work. Add 2 back. If the result is not a perfect square, the answer is wrong, and you know it in about five seconds: 

47 + 2 = 49 = 7²   ✓ survives the check
2207 + 2 = 2209 = 47²   ✓ survives the check

And a made-up wrong answer, to show the check biting. Suppose someone reports x⁴ + 1/x⁴ = 200: 

200 + 2 = 202.  14² = 196, 15² = 225.  202 is neither.
So 200 cannot be right, whatever route produced it.

This is worth doing every single time, because the method here is short and the arithmetic is where the real risk lives. A slip inside a two-digit square looks exactly like a wrong method from the outside — the check tells them apart.

Do it once with a letter, and you never do it again

Everything above pressed the button on a number. Nothing forces that. Press it on a letter instead — say x + 1/x = a, with a standing for whatever it happens to be — and the arithmetic disappears entirely: 

x² + 1/x² = a² − 2

Now feed that back in. Square it and subtract 2, exactly as before:

x⁴ + 1/x⁴ = (a² − 2)² − 2
          = a⁴ − 4a² + 4 − 2
          = a⁴ − 4a² + 2

That is the whole family, solved at once. Any problem of this shape is now a substitution rather than a calculation — and notice there is nowhere in the last three lines for an arithmetic slip to hide, because there is no arithmetic.

The cube machine gives its own formula the same way: 

x³ + 1/x³ = a³ − 3a

Two ways to use this, and both are worth having. Given x + 1/x = 10 you can now go straight to a⁴ − 4a² + 2 = 10000 − 400 + 2 = 9602. Or you can climb rung by rung: 10² − 2 = 98, then 98² − 2 = 9602. Same answer, necessarily — and running both is the strongest arithmetic check there is, because the two routes have almost no steps in common.

Do not throw the numeric route away. Working with a letter is faster and safer once you trust it, but the rung-by-rung version is what tells you the formula is true, and it is the one you can rebuild from scratch if you ever forget the formula. Aim to be able to do it either way, and to use each to check the other.

A second machine, for odd powers

Doubling can never land on an odd power, so the third power needs a different button. Cube instead of square: 

(x + 1/x)³ = x³ + 3x + 3/x + 1/x³
           = x³ + 1/x³ + 3(x + 1/x)

The leftover is not a bare number this time — it is 3 times the thing you already know. Move it across: 

x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x)

With x + 1/x = 3:

x³ + 1/x³ = 3³ − 3·3 = 27 − 9 = 18

Two machines, then. One doubles the power, one triples it. Combining them reaches lots of places: press the cube button then the square button and you land on the sixth power.

Your turn

Answers are here — open them after you have committed to something.

  1. Feed the machine 5. What comes out, and which power is it?
    Answer5² − 2 = 23. If the 5 was x + 1/x, then 23 is x² + 1/x². If the 5 had been x² + 1/x², then 23 would be x⁴ + 1/x⁴ — the machine genuinely does not care which.
  2. If x + 1/x = 9, what is x² + 1/x²?
    Answer79 — that is 81 − 2. Self-check: 79 + 2 = 81 = 9². ✓
  3. You are told directly that x² + 1/x² = 7. Find x⁴ + 1/x⁴, without being told x + 1/x at all.
    Answer47 — that is 7² − 2. Nothing about x + 1/x was needed. This is the same press as before, started from the middle: proof that the machine only ever looks at the number you hand it.
  4. If x + 1/x = 3, what is x³ + 1/x³?
    Answer18 — that is 3³ − 3·3 = 27 − 9. Note the self-check from earlier does not apply here: 18 + 2 = 20 is not a perfect square, and that is fine, because this answer came out of the cube machine, not the square one.
  5. Someone tells you that for some x, x⁴ + 1/x⁴ = 50. Can that be right?
    AnswerNo. 50 + 2 = 52, and 7² = 49 while 8² = 64, so 52 is not a perfect square. Since x⁴ + 1/x⁴ must be 2 less than the square of x² + 1/x², no x can produce 50.
  6. Harder: if x + 1/x = 3, what is x⁶ + 1/x⁶? There are two routes — take both and make them agree.
    Answer322. Route one: cube first to get x³ + 1/x³ = 18, then press the square machine: 18² − 2 = 324 − 2 = 322. Route two: press the square machine first to get x² + 1/x² = 7, then cube that: 7³ − 3·7 = 343 − 21 = 322. Two independent routes agreeing is the strongest arithmetic check there is.
  7. With a letter: if x + 1/x = a, find a formula for x⁶ + 1/x⁶ in terms of a. Then check your formula by putting a = 3 into it.
    Answera⁶ − 6a⁴ + 9a² − 2. Get it by cubing first — x³ + 1/x³ = a³ − 3a — and then pressing the square machine on that: (a³ − 3a)² − 2 = a⁶ − 6a⁴ + 9a² − 2. Check with a = 3: 729 − 486 + 81 − 2 = 322, which is exactly what the previous question got the long way. A formula that agrees with a number you already trust is a formula you can use.
  8. Why does the self-check (add 2, look for a perfect square) have to work? Answer it with a letter rather than with an example.
    AnswerBecause the last thing the machine ever does is subtract 2 from a square. Whatever value v goes in, what comes out is v² − 2, so adding 2 back always returns v² — a perfect square by construction, regardless of what v was. That is why no example is needed and no example could ever be enough.

What the check will ask
