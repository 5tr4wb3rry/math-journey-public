Lesson · Choosing vs. arranging; combinations

When the order is decided for you

Counting problems split into two kinds: ones where rearranging gives you something new, and ones where it doesn't. Telling them apart is most of the work, and some problems disguise which kind they are.

Start here

How many 3-digit numbers have digits that strictly increase?
(148 counts. 155 does not — the digits must go strictly up.)

This does not look like a choosing problem. It looks like you have to build numbers digit by digit, and the constraint links each digit to the one before it, so the usual "9 choices then 8 choices then 7" machinery jams immediately.

Then one observation dissolves it.

The observation

Pick any three different digits — say 4, 1, 8. How many strictly increasing numbers can you build from exactly those three? 

148  ✓ increasing
184  ✗    418  ✗    481  ✗    814  ✗    841  ✗

Exactly one. The six arrangements exist, but the constraint permits only one of them. Choosing the digits decides the order. There is no separate ordering step, because "increasing" is a rule with a single solution.

So the question is no longer "how many numbers can I build" but "how many sets of three digits are there" — and those are the same count.

The tell When a constraint forces a unique arrangement of whatever you pick, the problem is a choosing problem wearing an arranging costume.

Which digits are available? Not 0 — a 3-digit number cannot start with 0, and in an increasing number 0 would have to come first, being smallest. So the pool is 1 to 9.

choose 3 digits from 9, order irrelevant  =  C(9,3)

Choosing and arranging, side by side

Arranging counts ordered outcomes. Choosing counts unordered ones. They differ by exactly the number of orderings you decided not to distinguish. 

ARRANGE 3 of 9, order matters:   9 × 8 × 7 = 504
CHOOSE  3 of 9, order ignored:   504 ÷ 6 = 84

The 6 is 3! — the number of ways to shuffle any 3 chosen digits.

Written as a formula:

C(n, k) = n! / ( k! · (n−k)! )

C(9,3) = 9! / (3! · 6!) = (9 × 8 × 7) / (3 × 2 × 1) = 504 / 6 = 84

So there are 84 such numbers.

Easy to miss Counting the arrangements and forgetting to divide, or dividing by the wrong thing. The divisor is always k! — the shuffles of the k things you picked — never n!.

Sanity check on a size you can verify by hand:

2-digit strictly increasing numbers, digits from 1–9:
C(9,2) = (9 × 8)/2 = 36

Count directly: starting 1 → 12…19 is 8
                starting 2 → 23…29 is 7
                …
                starting 8 → 89     is 1
8 + 7 + 6 + 5 + 4 + 3 + 2 + 1 = 36  ✓

The decreasing case is not a mirror

Strictly decreasing 3-digit numbers look symmetric, but the digit pool differs — and this is where a careless mirror argument goes wrong.

Now 0 is allowed. In a decreasing number 0 lands at the end, never the front, so it breaks nothing: 320 is a perfectly good decreasing 3-digit number. 

choose 3 digits from 0–9  =  C(10,3) = (10 × 9 × 8)/6 = 120

84 increasing versus 120 decreasing. The asymmetry is entirely down to whether 0 can play — worth pausing on, because it is the kind of detail a symmetry argument hides.

Your turn

  1. How many 4-digit numbers have strictly increasing digits?
    Answer126 — C(9,4) = (9×8×7×6)/(4×3×2×1) = 3024/24. Same reasoning: pick 4 digits from 1–9 and the order is forced.
  2. Twelve people each shake hands once with everyone else. How many handshakes?
    Answer66 — C(12,2) = (12×11)/2. A handshake is unordered: you shaking my hand is not a second handshake.
  3. From 8 people, how many ways to pick a committee of 3?
    Answer56 — C(8,3) = (8×7×6)/6.
  4. From those same 8 people, how many ways to pick a president, a treasurer and a secretary?
    Answer336 — here the roles make order matter, so it is 8 × 7 × 6 with no dividing. Note 336 = 56 × 6: the same committees, each assignable to roles in 3! ways.
  5. Harder: how many 3-digit numbers have digits in non-decreasing order, so that repeats like 155 and 111 are allowed?
    Answer165. Repeats break the "choose a set" trick, because a set cannot hold 1 twice. Instead decide how many of each digit 1–9 you take, with the counts summing to 3. That is the stars-and-bars count C(3 + 9 − 1, 3) = C(11,3) = 165. Sanity check: 165 is larger than the 84 strictly increasing ones, as it must be, since every strictly increasing number is also non-decreasing.
